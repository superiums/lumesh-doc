## Styles

| Set Style | Reset |
|-----------|-------|
|   | RESET |
| BOLD | RESET_BOLD |
| DIM | RESET_DIM |
| ITALIC | RESET_ITALIC |
| UNDERLINE | RESET_UNDERLINE |
| BLINK | RESET_BLINK |
| REVERSE | RESET_REVERSE |
| HIDDEN | RESET_HIDDEN |
| STRIKE | RESET_STRIKE |

Usage:
```bash
STYLE.DIM + 'lume'
# Equivalent to
string.dim('lume')
```
