## Builtin Functions for Lib: filesize

- `b <filesize>`
	bytes

- `from <size_str|byte_int>`
	to Filesize

- `gb <filesize>`
	gigabytes

- `kb <filesize>`
	kilobytes (integer, truncated)

- `mb <filesize>`
	megabytes

- `tb <filesize>`
	terabytes

- `to_string <filesize>`
	to human readable string
