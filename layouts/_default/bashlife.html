Bash 泥泞人生路

系统梳理 Bash 的常见陷阱与反直觉设计

"Bash 的生存法则是——凡是允许省略的，最终都会炸。"

语法基础：空格敏感 & 赋值语法

● Bash
if[$a==$b]; then ... # ❌ 报错 if [ "$a" == "$b" ]; then ... a = 1 # ❌ 当作命令执行 a=1 # ✅ 不能有空格
● Lume
a == b if $a == $b { ... } a=1 a = 1 # 两种写法均合法

空格完全可选，表达式直接书写

字符串：隐式分割与 IFS 陷阱

● Bash
file="a b" rm $file # ❌ 删除两个文件 rm "$file" # ✅ 引号是护身符 # IFS 是全局的，牵一发动全身
● Lume
rm $file # 解析为 rm 'a b'，符合直觉 set LUME_IFS_MODE = 2 # 按场景精细控制分割行为

引号地狱 vs 模板字符串

● Bash
echo "Today is $(date "+%Y-%m-%d")" sed "s/foo/bar \"$var\"/g" file.txt curl -X POST -d "{\"name\":\"$name\",\"msg\":\"Hello '$msg'\"}" http://example.com # 嵌套超过两层就难以维护
● Lume
print `Today is {date '+%Y-%m-%d'}` sed `s/foo/bar "$var"/g` file.txt curl -X POST -d r#`{"name":"{name}", "msg": "Hello '$msg'"}`# http://example.com # 内部引号直接书写

三种字符串引号均原生支持#包裹和多行文本

类型系统：一切皆字符串的代价

● Bash
c=$a+$b # "1+2" 拼接 echo $((1/2)) # 0，无浮点 echo $((99999999999999999999)) # 溢出静默发生，不报错
● Lume
c = a + b 20 / 2.0 # 浮点全支持 echo 99999999999999999999999 # error: number too large to fit

数组与映射：记不完的特殊符号

● Bash
${arr[@]:1:2} # 切片 ${#arr[@]} # 长度 unset arr[1] # 下标不重排 declare -A map # 关联数组需提前声明
● Lume
arr[1..-1] # 切片 arr.len() arr.remove_at(1) # 自动重排 m = {a: 1, b: 2} # 独立映射类型

特殊类型：范围 / 文件大小 / 正则 / 时间

● Bash
# 范围、正则、时间均以字符串表示 # 无专用类型，无法直接参与运算
● Lume
1..=10 # 闭区间 Range 3M # FileSize(3MB) g'\d+' # 正则字面量 t'08:10' - t'08:09' # 时间差 60000

条件判断：[ ] vs [[ ]] vs (( ))

● Bash
[ "$a" -eq "123" ] # 整数比较 [ "$a" = 123 ] # 字符串比较 [[ "$a" =~ ^[0-9]+$ ]] # 三套语法，语义容易混淆
● Lume
a ~: g'\d+' a > 0 && b < 0 a == b # 无需括号，== 统一比较所有类型

返回值语义：退出码 vs 布尔值

● Bash
grep "abc" file.txt echo $? # 0 = 成功，与直觉相反 if grep "abc" file.txt; then ...
● Lume
let found = fs.read file.txt | .grep('abc') if found { echo 'found' } # 直接判断内容，不关心退出码

流程控制：case 陷阱 vs match 表达式

● Bash
case $1 in a) echo "a" ;;& b|c) echo "bc" ;; esac # ;; / ;& / ;;& 极易混淆
● Lume
match x { 1, 2, 3 => "small" 4..10 => "medium" r'^\d+$' => "numeric" _ => "other" } let r = if x > 0 { "pos" } else { "neg" }

函数：没有形参、只有退出码

● Bash
foo() { echo "$1"; } # 无参数名 foo() { return 100; } # 只能返回 0-255 time() { echo "my time"; } # 函数名会覆盖外部命令
● Lume
fn greet(name, greeting="Hello") { println greeting ", " name "!" } fn sum(*nums) { nums | list.fold((a,x)->a+x, 0) } time() # 调用函数 time _ # 调用外部命令

Lambda、闭包与柯里化

● Bash
# 不支持 Lambda # 不支持闭包 # 不支持柯里化 / 装饰器
● Lume
fn make_adder(base) { x -> x + base } let add5 = make_adder(5) add5(3) # 8 let multiply = (x, y) -> x * y let double = multiply(2) double(7) # 14，柯里化

作用域：全局污染 & 未定义变量

● Bash
func() { a=1; } func; echo $a # 1，全局污染 rm -rf /$undefined_dir # 未定义变量展开为空，灾难发生
● Lume
let a = 5 fn add() { a = 1 } add(); print a # 5，函数默认隔离 rm -rf /$undefined_dir # 识别为字面量，不会展开

管道：子 Shell 陷阱 & 纯文本流

● Bash
count=0 seq 10 | while read i; do ((count++)); done echo "$count" # 0，子 Shell 修改丢失 # 必须 echo 才能传出数据
● Lume
fs.ls -lh | where(size > 5K) [1,2,3] | .filter(x -> x > 1) | .map(x -> x*x) # 不启动子进程，结构化数据不丢失 ls -1 |> cp -r _ /tmp/ # 分发管道

IO：echo 陷阱 & 重定向噪音

● Bash
echo "-n" # 被当作参数 cmd > out.txt # 静默覆盖 cmd > all.log 2>&1 # 符号密集
● Lume
print "-n" cmd _ >! out.txt # 显式覆盖 command &+ > all.log # 合并输出 command &. # 忽略错误

通配符：未匹配时原样保留的地雷

● Bash
rm *.log # 无 .log 文件时，尝试删除名为 '*.log' 的文件 shopt -s nullglob # 需手动防御
● Lume
rm *.log # 报错：wildcard not matched rm *.log ?. # 忽略错误，继续执行

模块导入：source 全局污染

● Bash
source utils.sh # 同名函数无声覆盖 # 没有模块系统、没有命名空间
● Lume
use myutils as utils utils::my_function() # 17 个内置模块，按需加载

错误处理与调试

● Bash
set -euo pipefail echo "DEBUG: x=$x" set -x # 噪音如海啸 # syntax error near unexpected token '('
● Lume
risky_command ?: (e) -> { println "错误码：" e.code default_value } [1,2,3] | .map(x->x*2) | tap | .filter(x->x>3) # 7 种错误捕获操作符 + 编译器级提示

后台任务：不随主进程退出

● Bash
sleep 1000 & exit # sleep 仍在运行 trap 'kill $(jobs -p)' EXIT # 必须手动清理
● Lume
sleep 1000 & exit # sleep 自动随之退出 jobs -k id # 可选清理
