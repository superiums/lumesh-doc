Why Lume

Every Bash pitfall is a design starting point for Lume

Secure by default, explicit is better than implicit — 11 dimensions, tackling Bash's historical baggage one by one

⌨

Syntax

Bash

Space-sensitive, [ ]/[[ ]]/(( )) messy, no spaces in assignments

Lume

Spaces optional, == unifies comparison across all types, no magic parentheses needed

🔢

Type System

Bash

Everything is a string, need $(( )) for arithmetic, no floats, overflows don't error

Lume

Full types: integers/floats/arrays/maps/ranges/regex/time/file-size literals, operations written directly

❝

String

Bash

Implicit splitting+glob expansion is a minefield, nested interpolation escaping hell

Lume

Three string types (raw/escaped/template interpolation), StringSafe type prevents injection

🗂

Data Structures

Bash

Arrays/associative arrays syntax is cumbersome, no nested access support

Lume

Intuitive array/map literals, supports select (SQL-like) and get dot-path access

⤳

Flow Control

Bash

case has many pitfalls, only wildcard matching supported

Lume

match supports multi-value/range/regex matching; if/for can be expression return values

ƒ

Functions

Bash

Only positional parameters, return values can only be 0-255 exit codes

Lume

Named parameters, default values, variadic parameters, any return value, Lambda/closure/currying, decorators

🔒

Scope

Bash

Variables pollute global scope by default

Lume

Functions have isolated scope by default, parent scope modification requires explicit set

🔀

Pipes / Subprocesses

Bash

Right side of pipe runs in subshell, variable changes lost; can only pass text streams

Lume

Four pipe types (standard/positional/distribute/PTY), structured data flows directly, no subprocesses spawned

⚠

Error Handling

Bash

Relies on exit codes, need manual set -euo pipefail

Lume

Compiler-level error messages + 10 error catching operators

📦

Modularity

Bash

source pollutes global namespace, no module system

Lume

use ... as module imports + 22 on-demand built-in modules

⚡

Performance

Bash

About 2200ms for one million loops

Lume

About 200ms, 10x+ faster
