Why Lume

每一处 Bash 的陷阱，都是 Lume 的设计起点

安全默认，显式优于隐式——11 个维度，逐一击破 Bash 的历史包袱

⌨

语法

Bash

空格敏感、[ ]/[[ ]]/(( )) 混乱、赋值不能有空格

Lume

空格可选，== 统一比较所有类型，无需括号魔法

🔢

类型系统

Bash

一切皆字符串，算术要用 $(( ))，无浮点、溢出不报错

Lume

完整类型：整数/浮点/数组/映射/范围/正则/时间/文件大小字面量，运算直接书写

❝

字符串

Bash

隐式分割+glob 展开容易埋雷，插值嵌套转义地狱

Lume

三种字符串（原始/转义/模板插值），StringSafe 类型防注入

🗂

数据结构

Bash

数组/关联数组语法繁琐，不支持嵌套访问

Lume

直观的数组/映射字面量，支持 select（类 SQL）与 get 点路径访问

⤳

流程控制

Bash

case 陷阱多，仅支持通配符匹配

Lume

match 支持多值/范围/正则匹配；if/for 可作为表达式返回值

ƒ

函数

Bash

只有位置参数，返回值只能是 0-255 退出码

Lume

具名参数、默认值、可变参数、任意返回值、Lambda/闭包/柯里化、装饰器

🔒

作用域

Bash

变量默认全局污染

Lume

函数默认隔离作用域，改父级需显式 set

🔀

管道 / 子进程

Bash

管道右侧运行在子 Shell，变量修改丢失；只能传文本流

Lume

四种管道（标准/位置/分发/PTY），结构化数据直接流动，不启动子进程

⚠

错误处理

Bash

靠退出码，需手动 set -euo pipefail

Lume

编译器级报错提示 + 10 种错误捕获操作符

📦

模块化

Bash

source 全局命名空间污染，无模块系统

Lume

use ... as 模块导入 + 22 个按需加载内置模块
